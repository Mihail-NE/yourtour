# YourTour 🏔️

Добро пожаловать в репозиторий проекта YourTour - уникального веб-сайта, посвященного организации незабываемых туров по живописным местам нашей планеты.

## О проекте 🌟

Этот проект представляет собой современный адаптивный веб-сайт, разработанный с использованием передовых технологий веб-разработки. Сайт создан для туристической компании, специализирующейся на организации захватывающих путешествий по всем уголкам планеты.

### Ключевые особенности 🎯

- **Адаптивный дизайн**: Сайт прекрасно отображается на всех устройствах - от мобильных телефонов до широкоформатных мониторов
- **Современный UI/UX**: Интуитивно понятный интерфейс с плавными анимациями и стильным дизайном
- **Оптимизированная производительность**: Быстрая загрузка и плавная работа на всех устройствах
- **Интерактивные элементы**: Удобные формы бронирования и галерея изображений
- **Кроссбраузерная совместимость**: Корректное отображение во всех современных браузерах
- **SEO-оптимизация**: Структурированная семантическая разметка для лучшего ранжирования в поисковых системах

### Технологический стек 💻

- HTML5
- SCSS
- JavaScript
- БЭМ методология
- Адаптивная верстка
- Flexbox и Grid layouts
- Оптимизированные изображения

### Функциональность 🛠️

- Просмотр доступных туров
- Детальное описание маршрутов
- Форма заявки на бронирование
- Галерея фотографий
- Информация о компании
- Контактные данные
- Интеграция с социальными сетями
- Фильтрация туров по категориям
- Отзывы клиентов
